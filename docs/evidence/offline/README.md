# Offline kinematic evidence (NOT Webots, NOT physics)

Generated by `tools/offline_mission_sim.py`, which runs the real mission code
(FSM, docking, arm controller, gripper logic, A*, follower) against a simple
kinematic world: unicycle base, ray-cast LiDAR, rate-limited joints, geometric
finger/latch/palm-range models. It verifies logic, geometry and sequencing —
it says nothing about contact physics, grip stability or real sensor noise.

| file | content |
|---|---|
| `offline_manip_P3_B.csv` | manipulation log of one P3 → Zone B run |
| `offline_manip_timeline.png` | `tools/plot_manipulation.py` of that log |

Regenerate:
```bash
python tools/offline_mission_sim.py --quiet --csv docs/evidence/offline/offline_manip_P3_B.csv
python tools/plot_manipulation.py docs/evidence/offline/offline_manip_P3_B.csv \
    --out docs/evidence/offline/offline_manip_timeline.png --title "OFFLINE KINEMATIC SIMULATION ..."
```
